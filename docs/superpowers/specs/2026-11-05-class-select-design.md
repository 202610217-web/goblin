# 직업 선택 (기사 / 궁수) 설계

## 왜
지금은 모두 같은 캐릭터(체력 100, 사거리 2m)라 역할 차이가 없다. 중세풍 직업 두 개로
"앞에서 버티는 사람"과 "뒤에서 맞히는 사람"을 나눠 팀 플레이를 만든다.
궁수는 멀리 있는 상대를 맞히려면 앞을 보고 쏘는(리드샷) 실력이 필요해야 한다.

## 목표
- 방장이 로비에서 "게임 시작"을 누르면 5초 동안 모두 직업을 고르고, 끝나면 1라운드 준비(COUNTDOWN)로 간다.
- 직업 두 개: 기사(근접, 높은 체력), 궁수(원거리, 낮은 체력).
- 궁수 화살은 눈에 보이게 날아가고, 서버가 비행 중 판정한다. 날아가는 도중 상대가 방향을 바꾸면 빗나간다.
- 호스트 기기 방과 Cloudflare 방 모두 같은 서버 코드로 동작.

## 하지 않는 것
- 화살 낙차(중력), 화살을 보고 피하는 수준의 느린 속도
- 3번째 이상 직업, 경기 중 직업 바꾸기, 스킬/특수 능력
- 화면 쪽 판정 (조작 가능해서 금지)

## 만드는 방법 (고른 것: A)
- **A. 서버가 화살을 따라가며 판정 (채택)**: 쏠 때 화살(출발점, 방향, 속도, 시각)을 만들고 50ms마다 그 구간을 지나는 상대/벽을 확인. 공정하고 조작 불가. 서버 코드가 조금 늘어남.
- B. 쏘는 순간 도착 위치를 예측해 바로 판정: 가장 간단하지만, 상대가 중간에 방향을 바꿔도 맞음 → 리드샷 의미가 없어져서 제외.
- C. 화면 판정: 조작 가능해서 제외.

## 정한 것
### 흐름
- LOBBY → **CLASS_SELECT (5초)** → COUNTDOWN → ATTACK … (직업은 경기 시작 때 한 번만 고름. 라운드마다 다시 고르지 않음)
- 방장: 호스트 기기 방은 호스트 기기 사람, Cloudflare 방은 지금 방에 있는 사람 중 가장 먼저 들어온 사람(나가면 다음 사람).
- [내 판단] 4명 준비 시 자동 시작은 없앤다. 방장만 "게임 시작" 버튼을 누를 수 있고, 시작 조건(4명·2대2·모두 준비)이 맞을 때만 눌린다. "연습 시작"도 방장만.
- [내 판단] 5초 안에 안 고르면 직전에 고른 직업, 처음이면 기사.
- [내 판단] 더미는 무작위 직업.

### 직업 수치 (constants.ts에 모음, 시험해 보고 조정)
| | 기사 (검·방패) | 궁수 (활) |
|---|---|---|
| 최대 체력 | 150 | 70 |
| 데미지 | 25 | 25 |
| 사거리 | 2m (지금 근접 판정 그대로) | 최대 12m |
| 쿨다운 | 1.0초 | 1.4초 |
| 이동 속도 | 같음 (6m/s) | 같음 |

- 화살: 초당 30m, 직선, 최대 12m(0.4초). 처음 닿은 상대 1명 또는 벽(BOXES)에서 멈춤.
- 화살은 조준점 방향으로, 출발은 궁수 몸(가슴 높이)에서. 조준점 광선이 처음 닿는 지점을 향해 쏜다 (어깨 카메라라서 몸에서 그대로 쏘면 조준점과 어긋나기 때문).
- [내 판단] 치유 후 체력 = 그 직업 최대 체력의 30%.

### 통신
- 손님 → 서버: `{ t: "set_class", cls: "KNIGHT" | "ARCHER" }` (CLASS_SELECT 단계에서만), `{ t: "start_game" }` (방장만, LOBBY에서만).
- 서버 → 손님: `PublicPlayer.cls`, `PublicPlayer.owner`(방장 여부), 쏠 때 `{ t: "shot", by, origin, dir, at }` (화면이 같은 화살을 그림), 맞으면 기존처럼 방 상태로 체력 반영.
- 화살 비행 판정은 서버 메모리의 짧은 타이머(50ms 간격, 최대 8번)로 처리. 저장(storage)에는 넣지 않음 (0.4초 안에 끝나고, 쓴 행 수 무료 한도 보호).

### 화면
- CLASS_SELECT 동안 화면 가운데에 직업 카드 2장 + 남은 시간. 누르면 바로 표시, 다른 사람 선택도 이름 옆에 보임.
- 캐릭터 손에 직업 무기 모양(검 / 활)을 간단한 도형으로.
- 화살: 가는 막대 모양이 서버 시각 기준으로 날아가는 모습. 맞거나 벽에 닿으면 사라짐.
- 궁수는 쿨다운 표시를 1.4초 기준으로.

### 테스트
- 직업별 체력/쿨다운/사거리, 방장만 시작 가능, 5초 후 기본 직업 적용.
- 화살: 가만히 있는 상대 명중, 멀리서 옆으로 걷는 상대는 정면 조준 시 빗나가고 리드샷 시 명중, 비행 중 방향을 바꾸면 빗나감, 벽에 막힘.

## 만드는 사람에게 맡긴 것
- 화살·무기 모양의 세부 디자인, 카드 문구와 배치
- 화살 판정 반지름(캐릭터 상자 크기는 기존 근접 판정과 맞춤)
- 기존 재접속/연습/더미 흐름에 CLASS_SELECT를 끼우는 세부 처리
